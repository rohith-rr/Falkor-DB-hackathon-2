# Public fictional dataset

All people, projects and conversations here are synthetic. Plane and Slack-shaped
records demonstrate one connected engineering workflow; URLs are simulated and are
not evidence that those records exist in a real account. Immutable SourceRevision
nodes preserve the actual evidence text for offline inspection.

`manifest.json` declares identity mappings, component owners and explicit bindings.
`sources.json` holds the source records and fifty hand-authored interpretation labels.
`claim_labels.json` is the evidence-label catalog. `evaluation.json` freezes ten
development questions and twenty separate held-out questions. Expected concepts are
rubric hints, not automated answer scores.

The runtime deadline concern has an explicit closure by its raiser. The allocation
starvation concern remains open despite task completion, approval and proposed fixes.
Immediate retry is considered; unlimited retry is explicitly rejected. Ticket/chat
activity never grants code reviewer authorization or expertise credit.

See `docs/COMPANY.md` for import, MCP navigation, live configuration, and evaluation.
