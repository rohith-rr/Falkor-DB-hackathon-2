    Limits

    • Staged content, real records. The Plane and Slack content is a staged scenario about building Wayfinder. The API records, authorship, timestamps and the GitHub repository are real.
    • A small benchmark. 45 questions over one project, with gold annotated by the authors from the sources. It's a reproducible check, not a leaderboard. The graph strategy is a fixed planner, not an LLM agent.
    • Extraction recall is low. Interpretations are quote-checked but sparse. The benchmark's one miss is a decision the model never extracted.
    • Scores are structure. PageRank and betweenness rank connectivity, not importance, correctness or authority.
